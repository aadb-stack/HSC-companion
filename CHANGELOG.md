# Changelog

All notable changes to this project are documented here. The in-app **What's new**
page reads published GitHub Releases live, and the release workflow pulls notes
from the matching section below.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-06-30

### Added
- 🎉 First public release — "Aarambh".
- **Stream onboarding** for Science, Commerce and Arts with tailored dashboards.
- **Dashboard** with greeting, syllabus progress ring, study stats (streak, focus time), today's tasks and quick links.
- **Syllabus tracker** with real 2025-26 MSBSHSE chapter lists and per-subject progress, synced per user.
- **Formula sheet** — searchable, collapsible, accurate HSC Physics / Chemistry / Maths formulas (plus accounting ratios) from versioned JSON.
- **Flashcards** — user-created, with a Leitner-style study mode; cloud or on-device storage.
- **Pomodoro timer** with subject tagging and automatic session logging.
- **Textbook library** — direct links to official Balbharati / Government of Maharashtra e-textbooks (no PDFs hosted).
- **Previous year papers** — official MSBSHSE source links organised by subject and year.
- **GPA / percentage calculator** based on the Maharashtra HSC marking scheme and class boundaries.
- **Global search** (press `/`) over chapters, formulas and textbooks, powered by a CI-generated index.
- **Dark / light theme**, fully mobile responsive, installable as a PWA.
- **GitHub-native automation**: CI validation + Pages deploy, a daily board-source watcher, weekly study-reminder issues, and release publishing.
